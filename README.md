Perspectiva del proyecto:
**FRONTERA** será desarrollado como un proyecto con enfoque **educativo**,
utilizando un portón automatizado como ejemplo práctico para aprender y aplicar
conceptos de **programación, máquinas de estados, control de motores 
y comunicación Wi-Fi**. El sistema permitirá observar de manera práctica cómo interactúan 
el microcontrolador, sensores, actuadores y comunicación inalámbrica.


El Estudiante tendra el sentir de que esta aplicando inmediatamente lo que aprende.
